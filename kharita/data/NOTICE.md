Sampled colormaps keep 11 evenly spaced stops; published palettes (CARTOColors, ColorBrewer qualitative, the standards) keep their own colours. Ramps were generated by `tools/make_ramps.py` from matplotlib, cmcrameri, cmocean and palettable; none of these is a runtime dependency.

The full Tailwind CSS licence is in `LICENSE-tailwindcss.txt` beside this file and must ship with the package.
