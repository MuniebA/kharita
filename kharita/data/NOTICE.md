| File | Contents | Source | Licence |

| `ramps.json` | viridis, magma, plasma, inferno | matplotlib colormaps by Nathaniel Smith and Stefan van der Walt | CC0 |
| `ramps.json` | cividis | matplotlib, from Nunez, Anderton and Renslow (2018) | Distributed with matplotlib; confirm before release |
| `ramps.json` | blues, greens, reds, oranges, purples, ylorrd, ylgnbu, orrd, bupu, ylgn, rdbu, rdylbu, brbg, piyg, puor, set2, dark2, paired, set1 | ColorBrewer 2.0 by Cynthia Brewer, as shipped in matplotlib | Apache 2.0 |

Sequential and diverging ramps are sampled at 11 evenly spaced stops; categorical ramps keep their original colours.

The full Tailwind CSS licence is in `LICENSE-tailwindcss.txt` beside this file and must ship with the package.
